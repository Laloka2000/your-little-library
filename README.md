# Your Little Library

A web application for managing and organizing your personal book collection.

## Features

- **User Authentication**: Register and login to your account
- **Book Management**: Upload books with titles, content, authors, and cover images
- **Organization**: Browse and filter books by categories
- **Responsive Design**: Works seamlessly across different devices

## Tech Stack

- **Backend**: PHP
- **Frontend**: JavaScript, HTML, CSS
- **Database**: Not direct database, the code works from json files. 

## Usage

1. Create an account or login
2. Upload your books with metadata
3. Organize books by categories
4. Browse your library
